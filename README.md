# Task Tracker

This is a Python-based Task Tracker application that stores and manages daily tasks using file handling.

## Technologies Used
- Python

## Features
- Add daily tasks
- Save tasks to a text file
- Read existing tasks from file
- Display tasks by date
- Simple task management system

## Concepts Used
- File Handling
- Lists
- Loops
- Exception Handling
- User Input
- String Operations

## Project Type
Python File Handling Project
